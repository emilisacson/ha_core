# Anova Custom Integration

This integration allows you to control and monitor your Anova Precision Cooker from Home Assistant.

## Features
- Set and monitor temperature and cooking time
- Start/stop cooking remotely
- Real-time device status updates
- Binary sensors for device state (cooking, preheating, maintaining, safety, water level, etc.)
- Climate entity for temperature control
- Modern config flow with reauthentication and error handling
- Device registry and diagnostics support
- Full translation and internationalization

## Installation
1. Go to Home Assistant Integrations.
2. Search for "Anova Custom" and follow the configuration flow.
3. Enter your Anova account credentials.
4. Confirm device setup and start controlling your cooker.

## Removal
1. Go to Integrations in Home Assistant.
2. Find "Anova Custom" and click "Delete".
3. Confirm removal to clean up all entities and devices.
